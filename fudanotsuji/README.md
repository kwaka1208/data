# 八木札の辻交流館

こちらの[Google Mapsのリンク](https://maps.app.goo.gl/ijwDviEBqKdqys6F8)を頼りにお越しください。

## 電車の場合

1. 近鉄大和八木駅で降車し、南口からさらに南へ進みます。
2. カンデオホテルズ奈良橿原を超えたところの道を左（東）へ道沿いに進みます。
3. 信号を渡ってさらに東へ進みます。道が細くなりますが、車通りが多いので気をつけてお越しください。
4. しばらく行くと左手角にある古い和風の建物が八木札の辻交流館です。

## 車の場合
近くの公民館の駐車場に3台分の駐車場があります。駐車場は先着順ですので、いっぱいの場合は近隣のコインパーキングをご利用いただきます。
